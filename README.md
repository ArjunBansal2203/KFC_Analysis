# KFC_Analysis# 🍗 KFC Sales Analysis

Data analysis of **8,000 KFC sales records across 5 countries (2018–2024)** to understand sales, customer behavior, and marketing impact.

### 📊 Key Result
**Customer numbers + marketing spend explained 78.9% of sales variation.**

### 🔎 Key Insights
- 💰 Sales reached **$174.9M in 2024** (+6.04%)
- 👥 Higher customer traffic consistently correlated with higher sales
- 📈 Sales per customer improved **15.8%** across marketing-spend levels
- 🌍 **Canada** was the fastest-growing market (+3.84%)
